Мой Маркет PRO — база товарлар

Бул барак биринчи жолу гана колдонулат. Cloudflare Worker жана D1 даяр болгондо Worker URL жана BOOTSTRAP_SECRET киргизип, жетекчи менен администратордун аккаунттарын түзүңүз.

Коопсуздук: 10 белгиден кем эмес уникалдуу паролдорду колдонуңуз. Баштапкы ачкычты эч кимге жибербеңиз. Биринчи орнотуудан кийин Worker бул endpoint’ти кайра колдонууга уруксат бербейт.

Бул барак аккаунт түзүлгөндөн кийин жабылса да болот.

Андан соң app.js ичиндеги API_BASE талаасына ошол эле Worker URL киргизип, GitHub Pages'ке жаңыртыңыз.
